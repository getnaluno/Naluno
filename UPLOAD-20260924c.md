# Naluno 2026.09.24c

Unzip into the GitHub repo root so these files land in the folders that already exist (`app/`, `js/`, `css/`, `admin/`). Do not upload a new folder named `public`.

You do **not** need to publish `firestore.rules` for Seen by, reactions, or Advertise. Those use writes the server already allows.

Publish `firestore.rules` only if a Band still will not delete after everyone has been gone for two hours and the person who opened it is no longer on the member list. The clock itself is fixed in the app.

The economy worker is unchanged (`2.6.10-play`). Do not redeploy it.

What this pack changes:

- Android Back from Broadcast returns to the previous tab. It closes an open Broadcast, Band, or chat first. On the first screen, Back still leaves the app.
- Seen by and reactions actually write. They were looking for a database handle that was never put on `window`.
- Advertise still opens the form. Save sends the ad to the console and leaves it **paused**. Open the console once after this upload. The ad appears in inventory, held for review. Press **Go live** only after you have looked at it. Nothing is charged.
- A Band wipes two hours after the last person really left. Opening the empty room no longer restarts that clock. If the last message is already older than two hours and nobody is there, it wipes on the next look.
- Find Naluno leads with the street, not the city and the coordinate line.
- Saved broadcasts are no longer under Callsign. My Broadcasts has two transparent buttons: **Offline watch** (saved) and **Private broadcasts**.
