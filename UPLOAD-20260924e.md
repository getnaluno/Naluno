# Naluno 2026.09.24e

Unzip into the GitHub repo root so these files land in the folders that already exist (`app/`, `js/`, `css/`, `admin/`). Do not upload a new folder named `public`.

Publish `firestore.rules` with this pack. Without them, contribution totals still cannot be written back from the console when the economy service is quiet.

The economy worker is unchanged (`2.6.10-play`). Do not redeploy it.

What this pack changes:

- Ads in the console are rows. Tap a row for the book. Search sits on the inventory.
- Play on each row opens the creative, including an ad sent in from a Broadcast.
- Other long console lists are rows too. Tap one to open the rest of the line.
- Contribution totals add up from the ledger. If the service cannot be reached, the console does the sum itself and writes the profiles. It never lowers a total.
- The console refreshes on its own. The “New activity · Refresh” note is gone. A form you are filling is left alone.
- A message that cannot leave yet stays in Wireline, labelled Waiting in Naluno. It sends when this phone is back online. Try now is in the chat. It does not open the SMS app.
