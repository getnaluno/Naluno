# Build 20261021f — upload and deploy

The zip has every file changed since 19d (20a, 20b, 20c, 20d, 20e and 20f).

## 1. Upload to GitHub

Upload every file in the zip to the repository, keeping the folders, and
include `RELEASE.json`. Also delete these two old copies on GitHub (they are
not used and confuse searches): `workers/handler.mjs`, `workers/screen.mjs`.

## 2. Publish the database rules

Firebase console → Firestore → Rules → paste `firestore.rules` → Publish.
It adds the "stopped from reaching me" list and makes the database refuse a
blocked person's requests, messages and calls. Until it is published, blocking
is saved but not enforced.

## 3. Deploy both workers

- **Economy worker:** in the folder whose `wrangler.toml` says
  `naluno-economy`, put `naluno-economy-worker.js` in as `index.js` (as you do
  now), then run `npx wrangler deploy`. It adds the 30-day erase of deleted
  accounts, the person reports, the Wireline alert timing and every browser
  getting alerts. Check https://naluno-economy.naluno.workers.dev/health says
  `"version":"2.16.0-20261021e"`.
- **Call alert worker (new this build):** `cd workers/call-notify`, then
  `npx wrangler deploy`. This is the speed fix for call alerts. Check
  https://naluno-call-notify.naluno.workers.dev/health says
  `"version":"1.2.0-20261021e"`.

- **Compass worker (new, when you are at your computer):** `cd workers/compass`,
  then `npx wrangler deploy`. It replaces the old Compass worker with one that
  runs a stronger free model (Llama 3.3 70B on Cloudflare, falling back to a
  fast small one), merges instructions properly and asks again after a false
  refusal. It stays on Cloudflare's free daily allowance; nothing outside
  Cloudflare. If anything looks wrong, Cloudflare → Workers →
  naluno-compass → Deployments → roll back to the previous version. Check
  https://naluno-compass.naluno.workers.dev/health says
  `"version":"2.0.0-20261021f"`. The app's own Compass fixes work with the old
  worker too, so this step can wait.

## 4. Check the upload

Console → Health → **Is everything uploaded?** → Check now. It must say
"All … files match build 2026.10.21f", and both workers must show the versions
above. If a file is listed, upload it again and check again. A file can take
up to 10 minutes to appear.

Then Health → **How good is Compass?** → Ask Compass: eight everyday
questions, each answer shown, with any refusal marked.
