# Build 20261022a — upload

Includes 20g and 20h, and every file changed since 19d.

## What changed
**Compass in the app**
- An answer that goes round in circles ("X" no. I have it: "Y" no. …) is
  cut, and if it repeated itself again and again it is not shown at all.
- "From the app:" no longer starts an answer.
- Compass is told its own memory stops around the end of 2023. For new
  things (films, releases, who holds a job, prices) it trusts what was
  found on the web, and with nothing found it says there may be something
  newer instead of making up a title.
- A follow-up like "Way of Water is older, there is a newer release" now
  searches the earlier subject ("Avatar … 2026") instead of the words
  "older newer release". Pages about the newer film are no longer thrown away.
- Faster: the web search waits at most 3.5 s; the sign-in, place and
  weather are fetched at the same time as the search, not after it.

**The Compass worker** (workers/compass/index.js, 2.1.0-20261022a)
- Penalises repeating itself; a looping reply is asked again once, calmer,
  then handed to the next model. It is never sent to the phone looping.
- Remembers a checked sign-in for 5 minutes, so each message no longer
  waits on Google first.

**Console → Health → How good is Compass?**
- Signs in straight from the console's own account. With no sign-in it
  tells you so instead of asking Compass eight times.
- Marks an answer that WENT IN CIRCLES, and adds a ninth question about
  something new (the newest Avatar film).
- New file versions, so a phone can't keep using the old copy.

## Deploy
1. Upload the files.
2. **Deploy the Compass worker** (workers/compass): same as in 20f, e.g.
   `npx wrangler deploy` in workers/compass, or paste index.js in the
   Cloudflare dashboard for naluno-compass. No new settings.
   Nothing else: no database rules, economy and call-alert workers unchanged.
